# F2 Region aliasing rules and the meaning of in-place marks

## What

- Add WF-INPLACE= to the front end: a flagged input equals the output region text for text.
- Add the issue-time rule: inputs may overlap outputs only when equal and marked; outputs are pairwise disjoint.
- act-oracle checks both at each call; act-backend drops its implementation-defined copy for the marked case.

## Benefits

- Closes H1 and H2; `set_inplace` gains one meaning both generators share.

## Caveats

- Breaking: an ISA description that marks a differently-shaped input in place is rejected after this change.
- Overlap at issue needs interval arithmetic per access dimension; the oracle already has the loop machinery.

## Fail points

- A false positive on overlap blocks a valid kernel; the error names the regions and the iteration so it is visible at once.

## Order and dependencies

- Depends on L (S5.5 rewrite).
- Feeds O, B, T.

## Verification

- Tests: equal and marked passes; equal and unmarked rejected; partial overlap rejected; two outputs overlapping rejected.
