# F8 Front-end rejections the spec already implies

## What

- Reject `@a.` in a size, a dim, a backtick expression, or an update (H13).
- Reject output regions without a semantics block, and a buffer declared after an instruction (H18).
- Reject an initial state variable value outside i64 (H12).
- Warn on a value no later line reads (H19).

## Benefits

- Each is a few lines in `instruction.py` or `accelerator.py` and removes a "not rejected" row from S9.

## Caveats

- Breaking for an ISA specification that used `@a.` in a size; the error names the place.

## Fail points

- The `@a.` place check needs the place passed to `parse_text`, which already receives it (instruction.py:331).

## Order and dependencies

- Depends on L (S9 update).
- Language items: L10, L11, and L16 own the work.
- Feeds T.

## Verification

- One rejected program per bullet in the conformance suite; `examples/` still accepted.
