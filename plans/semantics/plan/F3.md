# F3 Total integer arithmetic: overflow and zero divisors fault the issue

## What

- Spec: every operator of an expression yields a signed 64-bit integer and every divisor is nonzero, else the issue faults; a fault writes no region and no state.
- act-oracle: replace `warn_width` with a `VF005` fault checked per operator on the tree as written, and stop wrapping looped starts in i64.
- act-backend: keep `checked_*`, `quotient`, `remainder`; "never selected" is the producer's form of the fault.

## Benefits

- Closes H4, H5, H12; removes two implementation-defined rows from S1.3, for no undefined behavior (owner decision 16).

## Caveats

- An ISA specification that relied on exact Python arithmetic past i64 now fails at the oracle.

## Fail points

- The oracle's loop expressions evaluate symbolically; an overflow at one iteration only must still be found, as `check_sizes` finds a nonpositive size.

## Order and dependencies

- Depends on L (S6.2 rewrite).
- Language item: L6 owns the work.
- Feeds O, T.

## Verification

- Tests: `2^62 * 4` as a size faults; `i64 min / -1` faults; `@c.n / @c.m` with m = 0 faults, and a constraint using it is a fault.
