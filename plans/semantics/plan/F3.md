# F3 Total integer arithmetic: overflow and zero divisors reject the issue

## What

- Spec: every intermediate of an expression is an i64 and every divisor is nonzero, else the issue is rejected; a constraint that fails this does not hold.
- act-oracle: replace `warn_width` with an error, and stop wrapping looped starts in i64.
- act-backend: keep `checked_*`, `quotient`, `remainder`; document "unselected" as the producer's form of rejection.

## Benefits

- Closes H4, H5, H12; removes two implementation-defined rows from S1.3.

## Caveats

- An ISA description that relied on exact Python arithmetic past i64 now fails at the oracle.

## Fail points

- The oracle's loop expressions evaluate symbolically; an overflow at one iteration only must still be found, as `check_sizes` finds a nonpositive size.

## Order and dependencies

- Depends on L (S6.2 rewrite).
- Feeds O, T.

## Verification

- Tests: `2^62 * 4` as a size rejected; `i64 min / -1` rejected; `@c.n / @c.m` with m = 0 rejected and the constraint using it false.
