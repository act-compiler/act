# F1 Static shape and element type checker in the front end

## What

- Implement the rules of `typing.md` and `typing-ops.md` in `taidl/taidl`, one function per operation family, run by `add_semantics` and again when regions arrive.
- Reject a line whose written type differs from the derived one; reject implicit broadcast or promotion.
- Share the rule table with act-oracle's `shapes.py` so the oracle's check becomes a re-run of the front end's.

## Benefits

- Closes H9 and H16: both generators receive only well-typed blocks.
- Removes the "shapes not checked" rows from S1.3 and S9.

## Caveats

- Dims given by expressions need symbolic reasoning; the first version checks literal dims and defers symbolic ones to issue time.
- Gather and dot rules are long; copy them from StableHLO's constraints verbatim.

## Fail points

- A rule stricter than StableHLO rejects a working ISA description; the conformance tests on `examples/` catch it.
- A rule looser than the oracle lets a disagreement through; T's cross-check catches it.

## Order and dependencies

- Depends on L (typing sections of the spec).
- Feeds O (oracle drops its own table), T, S.

## Verification

- Every example under `taidl/examples` still parses.
- One rejected program per rule in T, and act-oracle's `disagreement` agrees with the front end on every accepted one.
