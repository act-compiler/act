# F5 Numeric classes: exact, bounded, reduction identities

## What

- Spec S8.4 gains the class table of `dynamics.md`: movement, literal, integer exact, integer divide, float exact, special values, convert, bit cast, approximate, accumulating; it places each of the 75 words in a class.
- Integer `power` with a negative exponent, `min % -1`, and integer `dot` are stated; the oracle verifies the `power` values against XLA CPU.
- Each approximate word carries a bound in the spec, seeded from act-oracle's `docs/operations.md`; `dot`, `reduce_add`, and `reduce_multiply` carry the two Higham bounds with an overflow clause.
- Reduction identities become normative per `rulings.md`; a float sum starts from +0.0.
- Every float operation rounds once; the oracle sets `xla_allow_excess_precision`, `xla_cpu_ftz`, and `xla_cpu_enable_fast_min_max` false and tests denormals on the pinned jaxlib for each platform.
- Any NaN equals any NaN; `bitcast_convert` of a NaN gives the positive canonical quiet NaN; `maximum` and `minimum` follow IEEE 754-2019.
- `convert` follows the per-class rules of `dynamics.md`; `f32` to `f8e4m3fn` overflow gives NaN in the pinned `ml_dtypes`.
- A float literal rounds once from its exact decimal; one that rounds to an infinity is rejected.
- Stored NumPy values (T8) hold the exact classes bit for bit for conformance tests.

## Benefits

- Closes H6, H7, H15, H17, H21; a generator disagreement becomes a measurable bound breach.

## Caveats

- XLA CPU may not meet a tight bound for every transcendental at bf16; bounds start loose and tighten per word.
- Where `n*u >= 1` the accumulation bound constrains nothing; the author writes a wider result type.

## Fail points

- A tolerance written per word but tested per instruction hides a breach inside a long block; tests compare per line through the oracle's debug slices.

## Order and dependencies

- Depends on L (S8.4), U, F6.
- Language items: L31 and L32 own the work.
- Feeds O, T, C.

## Verification

- A test per word at each element type in its class, comparing the oracle against the stored NumPy values of T8 within the stated bound.
