# F5 Numeric classes: exact, approximate with tolerance, reduction identities

## What

- Spec S8.4 gains the class table of `dynamics.md`: integer exact, integer divide, float exact, float approximate, reduction.
- Each approximate word carries a tolerance in the spec, seeded from act-oracle's `docs/operations.md` bounds.
- Reduction identities become normative per `rulings.md`.
- A shared numeric reference (S) evaluates the exact classes bit for bit for conformance tests.

## Benefits

- Closes H6, H7, H15, H17; a generator disagreement becomes a measurable tolerance breach.

## Caveats

- XLA CPU may not meet a tight tolerance for every transcendental at bf16; tolerances start loose and tighten per word.
- Accumulation precision of `dot` stays approximate; an ISA needing an exact accumulator writes explicit `convert` lines.

## Fail points

- A tolerance written per word but tested per instruction hides a breach inside a long block; tests compare per line through the oracle's debug slices.

## Order and dependencies

- Depends on L (S8.4), S, F9.
- Feeds O, T, C.

## Verification

- A test per word at each element type in its class, comparing the oracle against the shared reference within the stated tolerance.
