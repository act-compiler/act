# F9 Mechanized core: the rules as an executable reference interpreter

## What

- A small Python interpreter of `dynamics.md` over NumPy, independent of XLA, for the integer exact and float exact classes.
- It issues an instruction against a memory state and control registers and returns the new state or the REQUIRE that failed.
- It is the shared code (S) that F5 and F7 compare against.

## Benefits

- A third reading of the spec that neither generator wrote; a disagreement between the oracle and the interpreter localizes to one rule.

## Caveats

- Covers exact classes only; approximate words defer to the oracle's tolerance tests.

## Fail points

- Drift between the interpreter and the spec text; each rule in the interpreter cites its line in `dynamics.md`.

## Order and dependencies

- Depends on F1, F3, L.
- Feeds F5, F7, S.

## Verification

- Runs mini_trn's `load_rm`, `store_rm`, `mov` bit for bit against act-oracle's trace.
