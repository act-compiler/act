# act-oracle bugs and defects

Bugs, silent deviations, misclassified errors and dead code, found by reading the code; the verification review ran the numeric ones on jax CPU.
Under owner decision 40 a generated oracle stops only on invalid assembly code or binary input, with an error that names the instruction and the clause.
A path that raises or computes a wrong result on valid input is a bug: D1, D2, D11, D19 and D21 compute wrong, and D28 and D29 raise on valid input.
D20, D23 and D31 are invalid input with a missing or wrong error; O31 audits the rest of the raise sites.
Severity: `high` is a possible silent wrong result, `medium` a wrong error class, hidden state or an unstated deviation, `low` dead code, duplication or a message.
The Plan column names the plan item that fixes it.
