# Review: act plan and glossary

Reviewer scope: `plans/act/`, `plans/glossary/`, `plans/terminology/`, checked against owner decisions 5, 6, 10, 14-17, 19-21 and rulings R5, R14, R50-R58.
The glossary is not yet one vocabulary: `terms.md`, `rulings.md`, and `words-to-avoid.md` still carry the terms that owner decisions 19-21 override, and the README only lists the overrides in prose.
Three further sources (`terminology/`, `language/spec-draft/glossary.md`, the backend and oracle naming todos) contradict it.
The v3 identifier lists are accurate where they exist (12 of 14 spot-checked file:line cites are exact) but cover only the front end, so generator, example, and umbrella consumers are missing.
The act plan is sound housekeeping for the current README, tests, and pins, but it does not yet make the project usable by a newcomer: it contradicts owner decision 6, has no item for the act side of the v3 release, never tests an install from a pinned tag, and has no quickstart.
Verdict: revise before use; two blockers, eleven majors, eight minors.

## Glossary terms the owner decisions override

| Glossary term | Required form after owner decisions |
| ------------- | ----------------------------------- |
| data model | All buffers and state of an accelerator; stays "data model" for the set; definition says "buffers and state" |
| tensor buffer (buffer) | "buffer"; banned: "tensor buffer", "data model" for one unit; `add_data_model` -> `add_buffer`; `DataModel` -> `Buffer`; Rust `Buffer` unchanged; backend prefix `Model` -> `Buffer` |
| global memory | "hbm": the built-in buffer `d0`; kernel argument `hbm`, `Buffer::HBM`, `'HBM'` unchanged, no rename; banned: global memory, off-chip memory, DRAM, main memory |
| access dimensions | Same term; definition "a region gives a start and a size for"; `dimensions` -> `access_dims` |
| base element, base element shape | Same terms; "of a buffer"; `unit_dim` -> `base_element_dims` |
| control register | "state"; banned: control register, initial state, register unqualified; `add_initial_state` -> `add_state`; `State` and `STATE` unchanged; `ControlRegister` and `control_registers` dropped; `Instruction.state` unchanged |
| initial value | Same; "the integer a state variable holds before the first instruction" |
| memory state | Same; "every buffer and all state at one point of a run" |
| control register assignment | "state update"; `update`, `update_asts`, `update_text` unchanged |
| data slice | "region"; `[buffer, starts, sizes]`; banned: data slice, slice alone, tile, window; `Region`, `check_regions`, `parse_regions`, `RegionTrees` unchanged, so the rename list for it is empty |
| input data slice / output data slice | "input region" / "output region" |
| data slice shape | "region shape" |
| start, size, presumed reshape, addressing attribute | Reword "data slice" to "region" in each definition |
| input value / output value | Same; "of input / output region k"; drop "region value" from the banned column |
| in-place mark | Per decision 17: "the output reuses the marked input's storage"; awaits the owner on R5 (AG7) |
| placement mark | Delete the row (R58 removes the marks) |
| undefined behavior | Delete; add "fault" (a defined run-time error that writes no region and no state, R55) |
| implementation-defined | Delete, or restrict to coverage status; decision 16 allows no open case |
| reject | Generation and kernel compile time only; run time is a fault |
| kernel function (kernel) | Short form "kernel" only for `@kernel`; prose "kernel function" |
| tensor accelerator (accelerator) | Same; GPU ruling reads "shared memory and register fragments are buffers, device memory is hbm" |
| words-to-avoid.md rows | Delete "HBM (for d0)"; flip "region -> data slice", "slice", "tile, window", "region value" to region; "state variable" and "state update" per AG3 and AG5; "register" -> "state, or buffer for a register file" |
| rulings.md rows | Replace the rows on one storage unit, persistent integer, d0, data touched, state change, GPU scope, scratchpad; drop the oracle `hbm` objection row |
| Source column | Cite "owner decision 19", "20" for the rows above, not [ACT] or [TAIDL] |
