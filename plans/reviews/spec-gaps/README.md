# Spec gaps

Gap reports on the TAIDL language specification draft, one per slice; each row gives a gap, the text to add or replace, and its outcome.

- [surface.md](surface.md): authoring surface, tracing, the check function, conformance, and the object model
- [layers.md](layers.md): width and encoding layers, derived attributes, generator metadata, and the generator contract
- [instructions.md](instructions.md): declarations, instructions, regions, markers, overlap, and the execution model
- [semantics.md](semantics.md): expressions, semantics, operations, numerics, and the fault table
