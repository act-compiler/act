# U9 One copy of docker and CI scripts

- What: `run.sh`, `exec.sh`, `cleanup.sh`, `chown.sh` and the env tag live in `act`; each repo keeps a thin wrapper with its container prefix.
- What: one reusable CI workflow in `act`, called from each repo's test.yml with its lint list.
- Benefits: act-backend/docker/run.sh and act-oracle/docker/run.sh differ only at :43-44 and the prefix today; taidl/docker/run.sh lacks the cuda13 variant.
- Caveats: a repo built alone must still fetch the scripts at a pinned tag.
- Fail points: a wrapper calling a script tag the image does not match; noticed by CI on each repo.
- Order and dependencies: with A, after U8; it lands after the v3 release.
- Verification: every repo's CI passes with the wrapper; the four env files reduce to one.
