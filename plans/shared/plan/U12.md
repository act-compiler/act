# U12 Authoring surface by tracing

- What: an ISA specification is a Python file; an instruction is a function decorated by `@acc.instruction`, run once by the tracer on symbolic attributes to build the typed node model of U2 (Q11.1).
- What: the tracer never reads function source; Python control flow on plain values runs at definition time and builds instruction families.
- What: standard library only; no parser, no ANTLR, no C++ toolchain (owner decision 41).
- What: attributes are parameters; `Comp[u7]` and `Addr[u16]` give kind and width, the default is `s64`, and no name carries meaning (owner decision 34).
- What: a region is `buffer.region(starts, size=sizes)`; `read(r)` and `write(r, value, inplace=x, apart=[y], no_partial_overlap=[z], may_overlap=[w])`; each marker names a read value of the same buffer (Q11.2).
- What: `require`, `any_of`, `all_of`, `acc.state` with `update`, `acc.encode` beside the instruction, and `meta=` at three levels.
- What: integer expressions use `+`, `-`, `*`, `//`, `%`, unary `-`, and the six comparisons; tensor values overload `+`, `-`, `*`, unary `-`; every other operation is `ops.<word>`.
- What: any other spelling raises at the author's line and names the spelling to use: `/`, `**`, `not`, `and`, `or`, `&`, `|`, chained comparison, `min`, `max`, `bool()`, `if` on a symbolic value, a slice, and `/`, `//`, `%` on a tensor (D17).
- What: every node records its call site (U2); the HLO-text printer of the `Model` shows what was understood and is a log format, never an input.
- Benefits: an error lands in the architect's own frame; the tree-to-model step leaves the shipped front end.
- Caveats: the spelling of `any_of`, `all_of`, and the type objects is the least settled part of the surface; the shape is fixed, the spelling may change before v3.
- Fail points: a spelling that takes a silent Python meaning; noticed by one test per raising spelling asserting the code and the line.
- Order and dependencies: after U3; before U13 and U14.
- Verification: for each corpus file the tracer builds the `Model` that the string front end builds (U13); the printed HLO text of every corpus `Model` reparses under the 2.x parser.
- Breaking: yes.
