# U2 Typed front-end contract with a version

- What: a documented typed Python model, a frozen `Model`, with buffers, state, instructions, and a typed node model for regions, operands, attributes, and integer expressions (Q3.4, Q11.3).
- What: the `Model` holds no ANTLR type and no `TerminalNode` key; until U14 the string front end builds it from its trees (taidl/taidl/instruction.py:34-57, :77-84).
- What: `CONTRACT_VERSION` in `taidl`, and a deprecation rule per member of one minor release; member names follow the L15 renames (buffers, regions).
- What: export the attribute order of each tensor operator as a list in taidl/taidl/operations.py, and generate the Rust table at act-backend/act_backend/generic/src/isel/initializer/expression.rs:173-178 from it (X7); cbindgen is allowed for the build.
- What: replace the oracle's parse of `array_dim_str` (act-oracle/taidl_to/api_generator.py:25) with `var_dim`, then drop `array_dim_str` and `num_dim_str` (taidl/taidl/data_model.py:39-40).
- What: expose `d0` as a named constant or flag instead of a string both generators match.
- What: the `Model` exposes each attribute's declared type (`s<w>` or `u<w>`, default `s64`), each instruction's encoding block (word width, fixed bits, slices) and its derived-attribute links, all `None` or empty when the layer is absent.
- What: every accelerator, buffer, and instruction node of the `Model` exposes its generator metadata as a read-only plain-data mapping keyed by namespace; `check` lists the namespaces present as a note and checks none of them.
- What: every node records the author's call site, the first frame outside `taidl` (Q3.5); a whole-instruction problem uses the first line of the instruction's function (Q11.2).
- What: a removed-names table drives one coded rejection (`RF`) for each removed v2 member or word (D15); no stub per member.
- Benefits: a front-end change that breaks a generator fails a test in `taidl`, not later in a generator's CI.
- Caveats: lands with the L15 renames so the contract is documented once, under the new names.
- Caveats: a serialized form is added at the second non-Python consumer, not before.
- Fail points: a member read by a generator but missing from the `Model`; noticed by a test that greps both generators for reads below their entry and diffs against it.
- Order and dependencies: after L15; before B13, L37, L40, and U11.
- Verification: the contract test builds `enc_mini` and a metadata corpus case (T32 to T35) and asserts the type, block, link, and metadata members, asserts each documented member exists with its type on the mini_trn examples, and checks that `CONTRACT_VERSION` changes with the member list.
