One row per bug or defect found by reading the code; nothing was run.
Severity: high is a wrong or crashing result on a spec or kernel a user can write; medium is an unchecked spec error or a fragile coupling that fails loudly; low is naming or dead weight.
Each fix sketch names the plan item that carries it.
