- [instructions.md](instructions.md): S5, attributes, regions, constraints, state updates, marks

- [operation_meaning.md](operation_meaning.md): S8.4 and S8.5, what each operation means, and the operations outside the language
- [conformance.md](conformance.md): S9, what a conforming front end rejects
